# Studio+

Clube de soluções: templates, créditos de API e descontos no catálogo.

```
BENEFICIOS.md          O que a assinatura libera
src/lib/entitlements.ts Regras de acesso (templates, créditos, %)
```

Use `entitlements.ts` no backend da loja / dashboard para checar o que o
assinante pode baixar e quantos créditos restam.
