# Provisionamento — Edge Hosting

1. Informe o repositório Git e o branch de produção.
2. Configure as variáveis de ambiente no painel.
3. O primeiro deploy gera a URL `*.edge.isstudio.dev`.
4. Aponte o domínio custom via CNAME para o target informado no e-mail.

## Limites do plano

- 3 projetos
- 100 GB de bandwidth / mês
- Preview deployments em PRs
- Backups diários (retenção 7 dias)

## SLA

Suporte 24/5. Incidentes P1: resposta em até 1h útil.
