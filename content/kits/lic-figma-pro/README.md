# Design Pack Pro

Biblioteca de 400+ assets licenciados para produtos digitais.

## Conteúdo deste pacote

Este kit inicial traz a **estrutura e a licença**. Os arquivos SVG/PNG do pack
completo entram no mesmo fluxo de resgate — o código continua o mesmo.

```
assets/icons/          Ícones SVG (amostra)
assets/illustrations/  Ilustrações vetoriais (amostra)
LICENCA-COMERCIAL.md   Termos de uso comercial
manifest.json          Inventário do pack
```

## Como usar

1. Importe os SVGs no Figma via **File → Place image**, ou copie o SVG cru.
2. Para React, importe com SVGR — SVGs limpos viram componente sem gambiarra.
3. Guarde `LICENCA-COMERCIAL.md` junto ao projeto do cliente.

## Licença resumida

- Uso em produtos comerciais e de clientes
- Modificar cores, traços e composição
- Não revender os assets como pack próprio
- Não publicar o pack original em bancos de imagens
